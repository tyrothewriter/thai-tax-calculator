# Thai Personal Income Tax Calculator

โปรแกรมคำนวณภาษีเงินได้บุคคลธรรมดาของไทย (อัตราก้าวหน้า) ด้วย Python ไม่ต้องติดตั้งไลบรารีเพิ่ม

## วิธีใช้

```bash
python tax.py 600000
python tax.py 1200000 --spouse --children 2 --parents 1 --social-security 9000 --life-insurance 50000
```

## อัตราภาษีที่ใช้

| เงินได้สุทธิ (บาท) | อัตรา |
|---|---|
| 0 – 150,000 | ยกเว้น |
| 150,001 – 300,000 | 5% |
| 300,001 – 500,000 | 10% |
| 500,001 – 750,000 | 15% |
| 750,001 – 1,000,000 | 20% |
| 1,000,001 – 2,000,000 | 25% |
| 2,000,001 – 5,000,000 | 30% |
| 5,000,001 ขึ้นไป | 35% |


## สามี-ภริยา: แยกยื่น vs รวมยื่น

`couple.py` เปรียบเทียบภาษีทั้ง 3 แบบตามคำชี้แจงกรมสรรพากร (ฉบับที่ 2, ปีภาษี 2555 เป็นต้นไป) แล้วบอกว่าแบบไหนประหยัดที่สุด

| แบบ | หลักการ |
|---|---|
| แยกยื่น | ต่างฝ่ายต่างยื่นในนามตนเอง หักลดหย่อนส่วนตัวคนละ 60,000 แต่หักลดหย่อนคู่สมรสไม่ได้ |
| รวมยื่นทั้งหมด | รวมเงินได้ทุกประเภทของอีกฝ่ายมายื่นในนามคนเดียว |
| รวมยื่นบางส่วน | เงินเดือนต่างฝ่ายต่างยื่นเอง ส่วนเงินได้ ม.40(2)-(8) ของฝ่ายหนึ่งไปรวมกับอีกฝ่าย |

ถ้าคู่สมรสฝ่ายหนึ่งไม่มีรายได้ โปรแกรมจะหักลดหย่อนคู่สมรส 60,000 ให้ฝ่ายที่มีรายได้อัตโนมัติ

```bash
python couple.py --a-salary 600000 --a-other-income 200000 --b-salary 100000
python couple.py --a-salary 800000 --b-salary 500000 --a-children 1 --b-children 1
```

ข้อสมมติ: เงินได้ ม.40(2)-(8) ให้ใส่ค่า *หลังหักค่าใช้จ่ายแล้ว*, บุตรร่วมกันให้ใส่ทั้งสองฝ่าย
(ต่างฝ่ายต่างหักได้เมื่อแยกยื่น), กรณีคู่สมรสไม่มีรายได้ให้ใส่ลดหย่อนทั้งหมดในฝั่งผู้มีรายได้ (บิดามารดารวมสองฝ่ายสูงสุด 4 คน)
ยังไม่รองรับเงินได้ที่ทำร่วมกันซึ่งต้องแบ่งกึ่งหนึ่งหรือตามสัดส่วน
